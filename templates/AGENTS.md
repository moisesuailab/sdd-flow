## SDD Flow

Read agents/RULES.md and the short map in agents/PROJECT.md.
Read agents/POLICIES.md for mandatory project-specific constraints.
Use sdd context SPEC_ID --phase PHASE --task TASK_ID for the current change; omit --task when no task is selected.
The catalog from sdd skills list contains discovery metadata; load only relevant skill bodies.
Follow the project's approval and autonomy settings. User authorization and tool permissions take precedence over project documents.
Keep current capability contracts separate from active changes and archived history.
See agents/AGENTS.md for lifecycle navigation and agents/SETUP.md for initial configuration.
For a broad or oversized request, use agents/prompts/intake.md before implementation.
